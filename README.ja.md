# Rey30 IDvj

Reinier Tamayo が保守するデスクトップ配布版です。ローカルモデル、アシスタント、設定とナビゲーションの構造を維持します。

構築手順と現状はスペイン語の [README.md](README.md) を参照してください。既定のローカルモデルは `Qwen3.5-9B-Q4_K_M`（`unsloth/Qwen3.5-9B-GGUF`）で、インストール元と実際のモデル名は維持されています。

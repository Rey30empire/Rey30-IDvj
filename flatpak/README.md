# Flatpak de Rey30 IDvj

La receta local es `com.rey30.idvj.app.yml`. Usa el checkout de esta distribución, el ID `com.rey30.idvj.app` y el ejecutable `Rey30-IDvj`; no vuelve a descargar el código de otra distribución.

La receta conserva los backends CUDA y Vulkan definidos en el origen. Requiere preparar las dependencias vendorizadas de Cargo y Yarn para la compilación sin red, además de los toolkits indicados. Debe validarse con Flatpak en Linux antes de distribuirse. No hay publicación en Flathub configurada ni capturas de esta distribución aceptadas para la tienda.

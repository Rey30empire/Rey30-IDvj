# Instalación en linux

Esta distribución se construye desde el repositorio. Consulta [Instalación de Rey30 IDvj](/download) y los requisitos de Tauri para tu plataforma. No hay una tienda ni un instalador público propio configurado.

El ejecutable de escritorio se llama `Rey30-IDvj`. Conserva la carpeta de datos y comprueba la migración antes de retirar una instalación anterior. La instalación del modelo local predeterminado mantiene su fuente real.

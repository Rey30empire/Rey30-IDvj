# OpenClaw

## Gateway local de Rey30 en Windows

Cuando la instalación ya incluye el perfil `rey30-idvj`, abre **Configuración → Servidores MCP → Conectados**. El puente **OpenClaw** usa el Gateway de ese perfil en `127.0.0.1:18809`. El inicio de sesión de Windows arranca el Gateway bajo tu cuenta. La conexión usa un token guardado en un archivo privado del perfil de OpenClaw.

La verificación consultó las nueve herramientas y ejecutó `conversations_list` desde Rey30. Para recuperar conversaciones, configura primero el canal y su acceso en ese Gateway. El resultado vacío es esperado mientras el perfil carezca de canales y conversaciones enlazadas. [Guía de canales](https://docs.openclaw.ai/channels) · [Puente oficial](https://docs.openclaw.ai/cli/mcp/serve)

## Conectar otro Gateway

En la aplicación de escritorio, abre **Configuración → Servidores MCP → Configurar OpenClaw**. La conexión usa la CLI oficial y requiere un Gateway de OpenClaw en ejecución con los canales que quieras utilizar ya configurados.

1. Si la CLI no está en el PATH de Rey30, escribe la ruta absoluta de su lanzador en **Lanzador de OpenClaw** y pulsa **Actualizar revisión**. En Windows, el lanzador de una instalación con npm suele llamarse `openclaw.cmd`.
2. Pulsa **Guardar puente inactivo**. Rey30 conserva los demás servidores MCP y registra la conexión por stdio.
3. Pulsa **Conectar** cuando esté listo el Gateway. Si la conexión funciona, Rey30 muestra las herramientas publicadas por OpenClaw. Puedes consultar su estado y desconectarlo desde **Conectados**.

El comando del puente es `openclaw mcp serve --claude-channel-mode off`. Usa la configuración de acceso de la CLI. Si necesitas una instalación o configurar el Gateway, consulta la [guía oficial de instalación](https://docs.openclaw.ai/install).

El puente expone conversaciones que el Gateway ya puede enrutar, incluidos historial, eventos y envío por canales vinculados. La cuenta, la memoria de Kimi y los canales se administran en sus propias aplicaciones. Consulta la [documentación del servidor MCP de OpenClaw](https://docs.openclaw.ai/cli/mcp/serve).

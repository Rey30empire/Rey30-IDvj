# CLI de Rey30 IDvj

El ejecutable de terminal se llama `rey30-idvj`. Sin argumentos abre la consola interactiva de agentes. La aplicación de escritorio se llama `Rey30-IDvj` y administra su motor local y sus modelos por separado.

## Preparación

Compila o instala el runtime desde el código de este repositorio siguiendo [inicio del agente](/docs/agent/quickstart). No hay un canal público propio de instaladores ni actualizaciones automáticas.

Consulta los comandos de la compilación instalada:

```powershell
rey30-idvj --help
rey30-idvj cli --help
rey30-idvj config list
rey30-idvj cli models list
```

`cli models list` enumera modelos de los proveedores configurados; no descarga pesos por sí solo. El Hub del escritorio conserva la instalación del modelo Jan de 4B y sus identificadores originales.

## Consola y procesos de agentes

```powershell
rey30-idvj --safe
rey30-idvj cli agent --help
```

La consola usa modelos de un proveedor configurado, que puede ser un endpoint local o un servicio externo. Debes configurar ese proveedor antes de una conversación. Los servicios externos mantienen sus propias credenciales y condiciones.

Los clientes JavaScript y Python usan el proceso `rey30-idvj cli agent rpc`. Consulta el [ADK](/docs/agent/adk) y la [referencia CLI](/docs/agent/cli).

## Configuración y aislamiento

El perfil nuevo del agente usa `~/.rey30-idvj`. Se conserva compatibilidad con el perfil anterior cuando corresponde. Para pruebas, `REY30_CONFIG_HOME` permite elegir un directorio absoluto exacto para la configuración del agente. Una ruta relativa produce un error en vez de usar el perfil real.

`REY30_AGENT_HOME` selecciona la caché de runtimes descargados por el ADK; tiene una función diferente. Las pruebas de este repositorio fijan también las rutas de datos y temporales para aislar cada ejecución.

# Escritorio Rey30 IDvj

La aplicación mantiene conversaciones, asistentes, administración de modelos, herramientas y ajustes dentro de la estructura del proyecto base. Esta distribución la mantiene Reinier Tamayo.

Empieza por [instalación](/download) y [primer uso](/docs/desktop/quickstart). El Hub conserva la fuente y la instalación del modelo local predeterminado (`Qwen3.5-9B-Q4_K_M`). Los modelos externos mantienen sus nombres reales y sus propias condiciones.

- [Modelos](/docs/desktop/manage-models).
- [Asistentes](/docs/desktop/assistants).
- [Servidor API local](/docs/desktop/api-server).
- [Herramientas MCP](/docs/desktop/mcp).
- [Ajustes](/docs/desktop/settings).
- [Carpeta de datos](/docs/desktop/data-folder).

No hay una web de chat, tienda, canal de lanzamiento ni plataforma pública propia configurada. Las páginas del archivo histórico describen lanzamientos del proyecto base.

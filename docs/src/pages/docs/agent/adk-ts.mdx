# ADK JavaScript y TypeScript

El workspace incluye `@rey30-idvj/adk`. Requiere Node.js 20 o posterior. Instala las dependencias desde la raíz y compila el CLI según [inicio del agente](/docs/agent/quickstart).

No hay paquete propio publicado en npm. Usa el paquete local y pasa el ejecutable compilado:

```js
import { Rey30Runtime } from '@rey30-idvj/adk'

const runtime = await Rey30Runtime.start({ bin: process.env.REY30_BIN })
try {
  console.log(runtime.serverInfo)
} finally {
  await runtime.close()
}
```

Configura `REY30_BIN` con una ruta absoluta o añade `rey30-idvj` a PATH. Una conversación requiere configurar un proveedor y modelo reales. Las sesiones y las herramientas están documentadas en [ADK](/docs/agent/adk) y [herramientas del host](/docs/agent/adk-tools).

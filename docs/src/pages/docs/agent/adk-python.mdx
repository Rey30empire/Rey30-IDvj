# ADK Python

Instala el paquete local en un entorno virtual con Python 3.11 o posterior:

```powershell
python -m pip install -e ./adk/python
```

Compila el CLI según [inicio del agente](/docs/agent/quickstart) y configura `REY30_BIN` con su ruta absoluta. También puedes pasar `bin=...` directamente:

```python
from rey30_idvj_adk import Rey30Runtime

with Rey30Runtime.start() as runtime:
    print(runtime.server_info)
```

No hay paquete propio publicado en PyPI. El cliente usa la biblioteca estándar y el proceso `rey30-idvj`; una conversación requiere un proveedor y modelo configurados.

Consulta [herramientas del host](/docs/agent/adk-tools) y [runtime e instalación](/docs/agent/adk-runtime).

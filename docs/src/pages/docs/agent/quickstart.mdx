# Inicio del agente Rey30 IDvj

El runtime de terminal se compila desde este repositorio. Sigue los requisitos de compilación del README principal y ejecuta desde la raíz:

```powershell
cargo build --locked --manifest-path src-tauri/rey30-idvj-cli/Cargo.toml --no-default-features --features cli --bin rey30-idvj --target-dir ./src-tauri/rey30-idvj-cli/target
.\src-tauri\rey30-idvj-cli\target\debug\rey30-idvj.exe --help
```

En Linux y macOS el ejecutable se llama `rey30-idvj`. Usa su ayuda para consultar comandos y configura un proveedor antes de pedir una tarea. Las credenciales y límites dependen del proveedor elegido. No hay un instalador nightly propio ni un canal de actualización público configurado.

El agente de terminal y el motor local de escritorio tienen dependencias distintas. La instalación del modelo local predeterminado del escritorio (`Qwen3.5-9B-Q4_K_M`) se conserva; compilar el CLI por sí solo no instala ese modelo.

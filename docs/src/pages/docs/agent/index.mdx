# Agente Rey30 IDvj

El runtime de terminal permite sesiones, herramientas del host y clientes JSON-RPC. Se construye como `rey30-idvj` desde este repositorio. La distribución no configura un canal de descarga o actualización público propio.

- [Primer uso](/docs/agent/quickstart).
- [Referencia CLI](/docs/agent/cli).
- [ADK](/docs/agent/adk).
- [JavaScript y TypeScript](/docs/agent/adk-ts).
- [Python](/docs/agent/adk-python).
- [Manifiestos de runtime](/docs/agent/adk-nightly).
- [Protocolo](/docs/agent/protocol).

Los clientes conservan los contratos serializados necesarios para interoperar con sesiones existentes. Las fuentes y marcas de modelos o servicios externos mantienen sus nombres reales.

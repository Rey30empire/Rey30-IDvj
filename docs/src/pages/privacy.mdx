# Privacidad de Rey30 IDvj

Las conversaciones y los modelos locales se almacenan en el perfil elegido por el usuario. Usar un proveedor remoto, descargar modelos, conectarse a un servidor MCP o activar una herramienta de red puede enviar información fuera del equipo según esa función.

Esta documentación local no activa analítica de terceros. No hay un servicio de privacidad o telemetría propio configurado para este sitio. La aplicación y sus dependencias deben revisarse por separado antes de distribuir una política de privacidad completa.

Retira credenciales y datos privados antes de compartir registros. Consulta [soporte y procedencia](/support) para los límites de esta distribución.

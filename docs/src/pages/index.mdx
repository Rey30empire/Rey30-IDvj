# Rey30 IDvj

Aplicación de escritorio para usar modelos locales, asistentes y herramientas. Esta distribución conserva la navegación y la organización del proyecto base.

- [Preparar el escritorio](/docs/desktop/quickstart).
- [Consultar las guías](/docs).
- [Configurar el runtime de agentes](/docs/agent/quickstart).
- [Construir esta distribución](/download).
- [Soporte y procedencia](/support).

El modelo local predeterminado (`Qwen3.5-9B-Q4_K_M`) mantiene su fuente e identificadores reales. La distribución no cambia la autoría del modelo ni de las dependencias.

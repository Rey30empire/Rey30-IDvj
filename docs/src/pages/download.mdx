# Instalación de Rey30 IDvj

La distribución se construye desde este repositorio. No hay una tienda, descarga pública ni canal de actualización propio configurado. Los instaladores del proyecto base pertenecen a otra distribución.

Desde la raíz del repositorio, sigue los requisitos del README y ejecuta:

```powershell
corepack yarn install
corepack yarn build:tauri:plugin:api
corepack yarn build:core
corepack yarn build:extensions
corepack yarn dev
```

Para preparar el instalador se utiliza `corepack yarn build`. El nombre del ejecutable es `Rey30-IDvj`. La compilación requiere las herramientas nativas de Tauri y del motor elegido.

El catálogo conserva la instalación del modelo local predeterminado; descargar sus pesos requiere conexión y espacio suficiente. Consulta [las guías del escritorio](/docs/desktop/quickstart).

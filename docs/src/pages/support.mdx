# Soporte y procedencia

Reinier Tamayo mantiene la distribución Rey30 IDvj. Para investigar un problema, registra versión, sistema operativo, pasos de reproducción y registros sin claves ni datos privados. Este repositorio no configura un canal público propio ni compromisos de respuesta.

La aplicación se distribuye bajo Apache 2.0. Ver NOTICE para las atribuciones de licencia; los avisos originales se mantienen en LICENSE y NOTICE. Los modelos, servicios y dependencias externos conservan su procedencia y sus propias condiciones.

La documentación empresarial y promocional del proyecto base se retiró de esta distribución. Su historia permanece en Git y sus avisos legales en LICENSE y NOTICE.

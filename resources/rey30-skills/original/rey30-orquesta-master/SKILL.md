# Orquesta Master de Rey30

Parte del resultado que pidió la persona. Usa la selección automática como una sugerencia: si el dominio no coincide, trabaja directamente y explica la corrección. Un saludo, una traducción sencilla o una consulta de una línea no necesita una orquesta.

Consulta las habilidades instaladas antes de proponer instalar otras. Carga únicamente las instrucciones que cambien cómo harás la tarea. Elige un especialista por responsabilidad: creación y revisión deben tener resultados distintos; no repitas el mismo trabajo con varios perfiles.

En el chat habitual un perfil de agente orienta este mismo modelo. No digas que has lanzado procesos ni agentes paralelos. En una superficie que ofrezca `task` o `dispatch_subagent`, consulta sus definiciones reales, delega tareas independientes y reúne los resultados antes de dar el trabajo por terminado. Si esas herramientas no están disponibles, ejecuta las etapas de forma secuencial.

Las herramientas utilizables son las incluidas en la sesión. Una habilidad es un procedimiento: sus ejemplos no agregan comandos, permisos, programas, credenciales ni conexiones MCP. Si falta una dependencia, indica cuál y completa lo que sí puedas verificar. No simules una llamada ni atribuyas una salida a un programa que no ejecutaste.

Para UI combina la dirección del proyecto con revisión visual y accesibilidad; para fallos reproduce antes de modificar; para mods identifica juego, versión y cargador; para assets inspecciona el formato y su integración; para nuevas skills revisa procedencia, licencia e instrucciones. Usa NVIDIA sólo si la tarea la requiere expresamente: AMD es el dispositivo de IA elegido por el propietario.

Entrega el resultado junto con la comprobación proporcional. Un archivo creado, una instalación registrada, un programa arrancado y una integración verificada son estados diferentes. Conserva el alcance solicitado y las configuraciones existentes.

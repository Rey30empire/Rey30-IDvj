# MiroFish — guía propia de simulación

Fuente: [666ghj/MiroFish](https://github.com/666ghj/MiroFish). El programa externo tiene licencia AGPL y requiere su entorno Node/Python, un proveedor LLM y la configuración Zep de esa versión. Esta habilidad no instala esos servicios ni activa cuentas.

Define la pregunta de la simulación, población, horizonte, supuestos y una observación con la que contrastar sus resultados. Una simulación de agentes no demuestra que una predicción social o económica sea verdadera.

Inspecciona el proyecto y la configuración existentes antes de preparar un experimento. Revisa manifiestos, versiones compatibles, formatos de entrada y pasos reales de ejecución. Usa datos públicos, sintéticos o autorizados; identifica qué se enviaría al modelo y a la memoria externa. No cargues documentos privados ni ejecutes una simulación que genere gasto fuera del encargo vigente.

Prepara una ejecución pequeña con límites de agentes, rondas y presupuesto cuando exista un entorno autorizado. Conserva entradas, parámetros, semilla cuando el programa la admita, versión y recibo de ejecución. No inventes métricas, conexiones ni resultados si sólo has generado una configuración.

Evalúa sensibilidad a los supuestos y compara con una referencia o evidencia externa. Expón variación y límites de interpretación. Si faltan API keys o servicios, entrega el experimento preparado y su bloqueo exacto; no cambies el backend AMD local para ocultarlo.

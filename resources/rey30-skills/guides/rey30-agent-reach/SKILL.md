# Agent Reach — guía propia compatible con Rey30

Fuente: [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach). La plantilla oficial contiene campos que su instalador debe generar; esta habilidad propia evita presentarla sin renderizar como lista para ejecutar. No instala el CLI ni copia sesiones del navegador.

Identifica la fuente que necesitas consultar y el canal concreto. Comprueba qué herramientas de lectura o búsqueda están ya conectadas a Rey30; si una resuelve la operación, úsala sin instalar otra colección.

Si existe una instalación Agent Reach autorizada, consulta su versión, ayuda y tabla de canales generada. No instales un paquete homónimo de PyPI: verifica el repositorio oficial y su procedimiento actual. Cada canal puede necesitar su propio CLI, navegador, clave o permiso.

No extraigas ni copies automáticamente cookies o sesiones de Chrome. Para fuentes privadas usa un mecanismo autorizado, con alcance explícito y sin imprimir credenciales. Evita exportar historiales a servicios externos sólo para habilitar lectura.

Ejecuta la búsqueda o lectura específica y cita el recurso recuperado; distingue resultado real de configuración preparada. Si faltan canal, autenticación o programa, informa exactamente cuál y ofrece las herramientas ya disponibles. No prometas acceso a todas las webs a partir del nombre de esta habilidad.

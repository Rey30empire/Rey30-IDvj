# OmniRouter — guía propia de integración

«Omniruter» puede referirse a varios proyectos o servicios. Una fuente revisada es [Godde3s/omnirouter](https://github.com/Godde3s/omnirouter); no asumas que una cuenta, URL o paquete con nombre parecido sea el mismo. Identifica repositorio o instancia desde archivos y configuración disponibles; pregunta la identidad si de ella depende conectar una cuenta.

Comprueba versión, licencia, plataformas y protocolo documentado. El candidato citado es un enrutador externo con opciones Go/binario. No instales helpers que reescriban otros editores ni importes sesiones del navegador durante el descubrimiento.

Para una integración OpenAI compatible, toma URL base, clave y modelo de la instancia real. Consulta el catálogo autorizado y verifica el formato de mensajes y errores. Conserva la configuración actual de Rey30 y ofrece el proveedor como conexión adicional.

Un router en loopback puede reenviar el contenido a la nube. Identifica el destino y las condiciones de cada proveedor antes de procesar datos privados. No extraigas cookies, eludas cuotas ni publiques el proxy sin autenticación. Si la identidad del proyecto sigue sin resolverse, entrega el análisis de alternativas con sus fuentes, no una instalación atribuida a un producto arbitrario.
